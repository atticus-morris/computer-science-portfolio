# Corner Grocer Item Tracker
# Project Summary 
For this project I built a C++ console application for the Corner Grocer to track and analyze daily item purchase frequencies. The main problem it solves is taking a raw text file of customer purchases (CS210_Project_Three_Input_File.txt), counting how many times each item was bought, and displaying that data through an interactive menu, while automatically generating a backup frequency.dat file right when the program starts.
I think I did a really good job with the architecture of the program. I used Object-Oriented Programming principles to separate my code cleanly into header and implementation files (ItemTracker.h and ItemTracker.cpp) instead of cramming everything into main.cpp. Choosing a std::map was also a great choice because it made item look ups super-fast and automatically kept everything sorted alphabetically.
To improve the code further, I could add stronger input validation so it handles weird user typing or unexpected file formatting better,and encrypting the backup file would make the data more secure. The trickiest part for me was getting the automatic file backup to run smoothly on startup without messing up the menu loop. I overcame that by carefully structuring the loadDataAndBackup() function and working through compiler errors using debugging tools. The modular design pattern, splitting declarations from implementations is a huge skill that will transfer directly to my future software projects, along with knowing how to use STL containers like maps.
